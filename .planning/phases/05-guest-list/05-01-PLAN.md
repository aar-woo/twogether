**getGuests(weddingId: string): Promise&lt;{ guests?: Guest[]; error?: string }&gt;**
- Auth check: `supabase.auth.getUser()`, return `{ error: "Not authenticated" }` if no user
- Query: `supabase.from("guests").select("id, name, side, relationship, invited, wedding_id, created_at").eq("wedding_id", weddingId).order("created_at", { ascending: true })`
- Return `{ guests: data ?? [] }` on success, `{ error: error.message }` on failure

**createGuest(name: string, side: string | null, relationship: string | null, invited: boolean): Promise&lt;{ error?: string }&gt;**
- Auth check: `supabase.auth.getUser()`
- Get wedding_id: `supabase.from("wedding_members").select("wedding_id").eq("user_id", user.id).single()`
- Insert: `supabase.from("guests").insert({ wedding_id: member.wedding_id, name, side, relationship, invited })`
- On success: `revalidatePath("/guests")` then return `{}`
- Wrap in try/catch; rethrow if `err.message === "NEXT_REDIRECT"`; otherwise return `{ error: "An unexpected error occurred" }`

**updateGuest(id: string, updates: Partial&lt;Pick&lt;Guest, "name" | "side" | "relationship" | "invited"&gt;&gt;): Promise&lt;{ error?: string }&gt;**
- Auth check same as above
- Update: `supabase.from("guests").update(updates).eq("id", id)`
- RLS enforces wedding membership — no need to check wedding_id
- On success: `revalidatePath("/guests")` then return `{}`
- Same try/catch pattern

**deleteGuest(id: string): Promise&lt;{ error?: string }&gt;**
- Auth check same as above
- Delete: `supabase.from("guests").delete().eq("id", id)`
