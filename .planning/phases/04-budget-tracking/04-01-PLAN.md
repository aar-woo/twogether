**Step 2: Create src/app/(app)/budget/actions.ts** with `"use server"` directive containing these 7 functions:

1. **`getCategories(weddingId: string)`** — query function (not a mutation). Select from `budget_categories` where `wedding_id = weddingId`, with nested `expenses(id, vendor_name, amount, date, status, note, created_at)`, ordered by `created_at ascending`. Return `{ categories?: CategoryWithExpenses[], error?: string }`.

2. **`createCategory(name: string, allocatedAmount: number)`** — auth check with `getUser()`, fetch `wedding_id` from `wedding_members` where `user_id = user.id` using `.single()`, insert into `budget_categories` with `{ wedding_id: member.wedding_id, name, allocated_amount: allocatedAmount }`. On success: `revalidatePath("/budget")` + `revalidatePath("/dashboard")`. Return `{ error?: string }`.

3. **`updateCategory(id: string, name: string, allocatedAmount: number)`** — auth check, update `budget_categories` set `{ name, allocated_amount: allocatedAmount }` where `id = id`. Dual revalidatePath. Return `{ error?: string }`.

4. **`deleteCategory(id: string)`** — auth check, delete from `budget_categories` where `id = id`. (ON DELETE CASCADE handles expenses.) Dual revalidatePath. Return `{ error?: string }`.

5. **`createExpense(categoryId: string, vendorName: string, amount: number, status: ExpenseStatus, date: string | null, note: string | null)`** — auth check, insert into `expenses` with `{ budget_category_id: categoryId, vendor_name: vendorName, amount, status, date: date || null, note: note || null }`. Dual revalidatePath. Return `{ error?: string }`.

6. **`updateExpense(id: string, vendorName: string, amount: number, status: ExpenseStatus, date: string | null, note: string | null)`** — auth check, update `expenses` set `{ vendor_name: vendorName, amount, status, date: date || null, note: note || null }` where `id = id`. Dual revalidatePath. Return `{ error?: string }`.

7. **`deleteExpense(id: string)`** — auth check, delete from `expenses` where `id = id`. Dual revalidatePath. Return `{ error?: string }`.

```typescript
import { redirect } from "next/navigation";
import { createClient } from "@/lib/supabase/server";
import { getCategories } from "./actions";
import { BudgetClient } from "./BudgetClient";

export default async function BudgetPage() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) redirect("/login");

  const { data: wedding } = await supabase
    .from("weddings")
    .select("id, name, total_budget")
    .maybeSingle();

  if (!wedding) redirect("/onboarding");

  const { categories, error } = await getCategories(wedding.id);

  return (
    <BudgetClient
      wedding={{ id: wedding.id, name: wedding.name, totalBudget: wedding.total_budget ?? 0 }}
      categories={categories ?? []}
    />
  );
}
```
